Enhancement Narrative

Algorithms and Data Structures

The artifact included in this enhancement is the database helper class for an Android inventory management application. This artifact was created a few months ago in my Android application development course, where I learned how to develop apps using Android Studio. I selected this artifact as a whole because it demonstrates my ability to create an application that provides innovative and efficient technology to users while highlighting my software development techniques. The component that showcases my software development skills the most within the inventory management artifact is the structure and efficiency of the artifact. I kept good coding practices by gathering requirements, creating a plan, and writing code and testing before pushing it out. The artifact was improved by porting the database helper class from a Java-based class into a Python class that utilizes SQL for its database. I did meet the course outcomes I planned in module one. I planned on porting the language from java android based to python based in order to show that I am able to design database in a vartiety of different environments and improve my codes efficiency. Through the enhancement of porting into Python I learned that different database operations remain pretty similar across different databases and languages, which makes it easier to understand how and why they work. One challenge I faced was converting the SQLite specific portions of code into MySql because of the difference in them.

Software Design and Engineering

The artifacts added to this milestone are the login activity and main activity classes for my Python-based inventory management application. These artifacts were originally created months ago as Java-based classes for an Android inventory management application. They control the various login features for the inventory management database, where users can access inventory operations for their account. I am including these artifacts in my ePortfolio as they show my integration of security features in an application, as well as database integration for a software application. I think that showcasing all-around skills involved in software development will create a strong profile for myself in both cybersecurity and software engineering aspects. For my enhancement focusing on algorithms and data structures, I turned the original array list used for the inventory into a class. This was done for better calculation efficiency, as dictionary lookup by key has an average constant-time complexity of O(1), which makes this data structure more efficient for direct item lookups as the inventory grows. These enhancements meet the course outcomes previously planned, as they utilize more efficient algorithms and data structures to improve the functionality of the application. Making the application's functionality better allows for improved use by users, making their experience more seamless. One important thing I learned was that data structures should be selected based on how data needs to be accessed and manipulated. Changing the inventory representation from a list of formatted strings to a dictionary of structured records made the purpose of the data clearer and allowed individual inventory items to be accessed using their IDs. This was a bit of a struggle to translate from JavaScript to Python, but I was able to figure it out eventually.
