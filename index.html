Web Development

JavaScriptTypeScript AngularNode.js ExpressMongoDB MongooseHTML CSSREST API JWT Authentication

Backend and Data

Security and Testing

Inventory Management System

Application Development

This project began as an Android inventory application written in Java and was enhanced by translating its core application and database functionality into Python with SQLite. The application includes user login and inventory-management features.

JavaAndroid PythonSQLite SQLOOP Database Design

Original Application

The original Android application used Java and SQLiteOpenHelper to support user accounts and inventory records, including adding items and updating quantities.

Download original Android project

Enhanced Application

The enhanced version uses Python and SQLite, with database helper functionality, login features, and inventory-management operations.

Download enhanced Python project

Software Design and Engineering

I selected this artifact because it gave me an opportunity to take an application I had already developed and rebuild its core functionality in a different programming environment. The enhancement involved translating the database helper and application logic from Java/Android into Python while retaining the purpose of the inventory system. This process helped me understand how similar database operations can be implemented across different languages and development environments.

Algorithms and Data Structures

As part of the enhancement, I changed the way inventory information was represented. Instead of keeping inventory data as a list of formatted strings, I used a dictionary of structured records so items could be accessed by their identifiers. This made the data easier to organize and reason about, and reinforced the importance of choosing data structures based on how an application needs to retrieve and update information.

Database Design

The enhanced application uses SQLite for local data persistence. Working through the language and database transition helped me compare database operations and understand how application logic interacts with stored user and inventory information.

What This Project Demonstrates

  • Translating application logic between Java and Python.
  • Relational database interaction and SQL operations.
  • User login and inventory-management workflows.
  • Using structured data and dictionaries for item lookup.
  • Debugging and adapting code across development environments.
